# Regatta Project

## Project Description

This project contains an example of a graphical application written in Java using the JavaFX graphics library.  
It is based on the Model-View-Presenter (MVP) architectural pattern.

The project is managed using the 'gradle' build system.

## Project Organization

The project has the following structure:

    .
    │
    ├── build.gradle, settings.gradle, gradle.properties
    │
    ├── .gitlab-ci.yml
    │
    └── src
        ├── main
        │   ├── java
        │   │      ├── fr.ensicaen.genielogiciel.project/*.java
        │   │      ├── fr.ensicaen.genielogiciel.project.model/*.java
        │   │      ├── fr.ensicaen.genielogiciel.project.presenter/*.java
        │   │      └── fr.ensicaen.genielogiciel.project.view/*.java
        │   │
        │   └── resources
        │          ├── fr.ensicaen.genielogiciel.project/view/*.fxml
        │          ├── fr.ensicaen.genielogiciel.project/view/*.css
        │          └── fr.ensicaen.genielogiciel.project/MessageBundle.properties.properties
        ├── test
            ├── java
            │      └── fr.ensicaen.genielogiciel.project/*.java
            └── resources
